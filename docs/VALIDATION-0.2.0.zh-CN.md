# XMLBridge 0.2.0 验证记录

日期：2026-10-20。macOS 27.0.1 / Apple Silicon。原生 SwiftUI 窗口调用随包 Python/lxml 引擎，不需要用户配置 Python。

- 409 项 Python 回归测试通过，涵盖既有精确时间与跨格式映射、旧 GUI 接口，以及新增的有损导出、保留未知内容、严格模式、停止决定、源文件改变、取消和本地 JSON 请求。
- 原生界面编译通过；打包包含 SwiftUI 入口与冻结引擎；独立 --self-test 通过，执行 FCPXML 1.8→1.9 结构迁移与 DTD 校验。打包签名检查通过。
- 在打包后的真实原生界面点击“添加文件或目录包”，通过系统选择窗口选择真实作品目录包的副本，正确识别 FCPXML 1.13、1 个项目、25 fps、96 个片段和 56 个素材；原生界面显示 330 项兼容或离线提示。
- 通过原生界面实际降为 FCPXML 1.8，生成 XML、HTML 与 JSON 报告；输出原始媒体路径结构已迁移，结构与时间线检查通过，源文件 SHA-256 未变。报告保留 330 项提示及 274 项处理决定。
- 原生界面批量添加目录，混合真实作品、含未知扩展的双项目样例和损坏 XML；勾选双项目样例中的第二个项目后导出。实际生成 2 / 3 个文件：真实作品正常生成；未知扩展保留且只含“项目 2”，结构检查如实显示未通过；损坏 XML 仅生成诊断报告。
- 未重新执行剪辑软件导入验证；本次输出在界面与报告中仍标为“目标软件尚未验证”。历史宿主样例范围见 CAPABILITIES.zh-CN.md。有损文件可生成不代表目标软件一定接受。
- 当前运行与原生界面实测只针对本机 macOS 27.0.1。macOS 13–25 的回退外观尚未实机验证；macOS 26 起使用系统玻璃控件。
