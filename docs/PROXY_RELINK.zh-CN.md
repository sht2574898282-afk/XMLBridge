# 代理回套原片

XMLBridge 0.3.0 在原生窗口顶部提供“版本转换”和“代理回套”两个入口。原来的版本转换保持原流程。

1. 添加 Premiere 导出的 XML，切换到“代理回套”。
2. 选择原片文件夹，填写代理尾缀（默认 S03；多个以逗号分开），点击“扫描匹配”。
3. 核对来源后勾选采用相应的原片。S03 仅用于寻找候选，软件不据此判断相机品牌。
4. 遇到多个候选，点击“选择候选”，在同一面板中比较完整路径、帧率、时长、时间码和分辨率。按日期、机位、卡目录判断；也可打开候选预览或手动指定文件。
5. 点击“生成原片回套 XML”，选择保存位置。完成后点击“显示 XML”，将这个新文件导入达芬奇。

当前支持 xmeml 4/5，输出保持输入的 XML 版本与剪辑结构。只更新明确采用素材的路径、素材文件名和宽高记录。未采用项保留原引用。

帧率差异与一帧差异只记录，不转换帧率、不补帧、不移动剪辑点。声道数、画面比例或较大时间码差异仍留待处理。参数相同也不能证明两个文件的画面相同。

原 XML、原片名称不变；同名输出不会覆盖。版本转换和代理回套各自生成结果，回套功能不会自动执行一次格式转换。

## 构建

Mac 包继续使用 SwiftUI 原生窗口与 XMLBridgeCore。原片参数由内置的 ffprobe 离线读取，ffprobe 仅链接系统库、禁用网络，不依赖 Homebrew。

此构建锁定 Qt 6.8.3 并使用兼容 macOS 13 的 ffprobe，以保持旧包的系统下限。支持的系统下限与该系统上的实际运行验收分别记录。

如果自行构建，先准备 FFmpeg 源码，然后运行 scripts/build_ffprobe_macos.sh，将生成的路径传给 XMLBRIDGE_FFPROBE；Python 构建环境使用 requirements-build.lock。
