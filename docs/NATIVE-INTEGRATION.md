# 原生界面接入 · 0.2.0

目标：安装到 /Applications/XMLBridge.app 的实际工具使用已展示的原生首次使用页与转换窗，不再启动旧版三栏界面。

1. 保留 Python/lxml 转换核心与命令行。添加本地 JSON 请求入口，由 SwiftUI 通过随包的引擎进程调用，后台处理、支持取消；不依赖系统 Python。
2. 同格式转换增加显式 allow_risky 选项，默认核心行为保持严格。原生界面默认允许有损处理；已知简化按清单执行，无法映射的扩展保留并记录。检查失败仍可输出，但不得显示通过。损坏 XML、格式不明、无效版本、无效项目选择、源文件已改变仍需停止；跨格式无映射结构仍停止。
3. 原生窗口实现空状态、文件与目录包选择、拖拽、批量队列、目标格式/版本/软件、项目选择、真实问题与逐项决定、输出目录、结果检查与报告入口。
4. 打包原生入口与冻结引擎，保留 CLI 和旧 GUI 调试入口；同步图标与源码归档。备份旧安装，再替换 /Applications 内应用。

验收：核心回归与风险导出测试、JSON 桥接混合批次/项目/取消测试、Swift 编译、应用签名/独立自检；从已安装应用用“添加”选入真实目录包，实际完成降级并核对 XML 与 HTML/JSON 报告，截图确认新版界面。
